# 你好，世界

这是这个站点的第一篇文章。写它的时候，首页的轮换背景还没换上真正的插画，只有一层紫色的渐变光。

## 为什么要自己搭一个站

平台很好用，但总有些东西不适合放在别人的时间线上：写过的小工具、踩过的坑、半夜三点想明白的一件事。放在自己的域名下，它们至少不会因为平台改版而消失。

> 有一个自己的角落，比在广场上喊话更舒服。

## 这个站会写什么

- 写代码时踩到的坑，以及最后怎么绕过去的
- 折腾各种工具的记录（比如这次搭站本身）
- 一些和代码无关的、二次元相关的东西

## 技术上是这样的

整站是纯静态的：`npm run build` 生成一堆 HTML，推到 GitHub 之后由 Actions 自动发布到 GitHub Pages。

```bash
npm install
npm run dev      # 本地预览
npm run build    # 生成 dist/
```

发文章只要往 `content/posts/` 里丢一个 Markdown 文件：

```md
---
title: 文章标题
date: 2026-10-21
lang: zh
summary: 一句话摘要
tags: [标签]
---

正文从这里开始。
```

写完 push 上去，几分钟后线上就有了。
