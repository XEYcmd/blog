## 引言

你是否经常在QQ群里看到各式各样的机器人，有的可以在各种群看到，有的是群主自己养的机器人，有着各种各样的功能。你是否也想拥有一个自己的机器人，接下来就会为你介绍一种常见的创建QQ机器人的方法。

> 本教程为家用电脑教程，使用时需电脑时刻开机并运行相关软件。有时刻使用需求的，需要自备服务器，详见官方文档，本文章不做讲解。

## AstrBot

[AstrBot](https://astrbot.app/) 是一个跨平台 AI 助手，让 AI 直接工作在你的聊天软件中，实现自动化任务与智能协作，同时提供灵活的 Agent 编排能力。它是目前各大群中常用的工具，它的插件市场就能几乎满足你的需求，并不需要自己再开发插件，并且它的部署也是十分方便、快捷、简单。

### 注意事项

- 当机器人部署成功后，与他聊天需要 @ 他，再跟上聊天的内容
- 该机器人只可用于自己为群主的群中
- 如果想将 bot 用于更广阔的地方，可尝试自备闲置 QQ 号，使用 NapCat + AstrBot 方式

### 准备工作

#### 注册 QQ 开放平台

前往 <https://q.qq.com/> 用你的 QQ 号注册即可。个人建议最好实名认证，这样功能才会更全一些。

#### 一个 QQ 机器人

如果你比较懒，并且这个机器人只用于 AstrBot，可以在 AstrBot 中扫码一键创建 QQ 机器人（**扫码的 QQ 号为你 QQ 开发平台注册的账号**）：

1. 进入 AstrBot 的 WebUI，点击左边栏「机器人」，然后点击「+ 创建机器人」。
2. 选择「QQ 官方机器人（WebSocket）」。
3. 在「选择创建方式」中选择「扫码一键创建」，点击开始创建后，用手机 QQ 扫描页面中的二维码。
4. 扫码确认后，AstrBot 会自动写入 AppID 和 AppSecret。确认「启用」已勾选，然后点击「保存」。

或者你比较勤快，可以在 QQ 开放平台手动创建 QQ 机器人，并记下 AppID 和 AppSecret。

> **一定要保存好你的 AppSecret**，它不会再次明文显示，只能重置后才能看到新的密钥。

#### 下载 AstrBot

前往 AstrBot 的 GitHub 仓库下载桌面版（Windows）程序：[AstrBot-desktop releases](https://github.com/AstrBotDevs/AstrBot-desktop/releases)

### 配置你的 AstrBot

点开「欢迎」选项卡，你就能看到快速引导，按照它的三步走即可。

### 配置 AI 模型

你可以点击三步走中的「去配置」，也可以点开「模型供应商」选项卡（建议）。作为基础，我们只需要配置对话选项卡下的内容。

1. 点击「新建」，可以看到很多预设的模型供应商。
2. 我个人比较推荐使用 **DeepSeek**（大家常用的模型）、**Google Gemini**、**OpenAI（ChatGPT）**。
3. 选择你想用的模型后，去它官方的 API 网站充值并创建 API Key（上网搜索对应模型的 API 网站即可）。

> **API Key 一旦创建只会在创建时显示**，之后都不会明文显示，务必保存好，不要泄露。

**以 DeepSeek 为例：**

1. 访问 [DeepSeek 开放平台](https://platform.deepseek.com/) 注册账户。
2. 给账户充值，用于消耗。
3. 前往「API keys」创建你的 API Key 并记住它。
4. 点开下方「商品定价」，结合你的预算酌情选择 Flash 模型还是 Pro 模型。

**对于 AstrBot 没有预设的供应商：**

需要去官方文档查找它的 BASE URL（OpenAI 格式）和你要使用的模型名称，然后在新增供应商时选择第一个「OpenAI 格式」，逐一填写：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| API Base URL | 供应商提供的接口地址 | `https://api.xxx.com/v1` |
| Model | 具体模型名称 | `gpt-3.5-turbo` |
| API Key | 你申请的密钥 | `sk-...` |

因为 AstrBot 有 DeepSeek 模型的预设，所以用 DeepSeek 就不用填这些。

### 配置平台机器人

这里选择「机器人」→「创建机器人」，选择它支持的平台，并按照提示进行即可。

**进行到这里，你的 Bot 后台已经接入了你选择的 AI 大模型，我们便可以进行功能方面的配置了。**

### 插件

打开「插件」一栏，选择「插件市场」，这里面有很多他人写好的插件可以选择。请选择支持平台中有你机器人平台的插件才能使用。当然，如果没有找到你心仪的插件，可以自己写，详见 AstrBot 官方文档。

### 人设

你可以在「人设」设定中写出你理想中的机器人人设并使用。
